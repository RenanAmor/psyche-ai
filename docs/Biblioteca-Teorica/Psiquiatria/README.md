## Status

Vazia nesta Sprint. Não é um dos seis itens nomeados explicitamente no briefing (§5), mas existe como pasta de primeiro nível desde a estrutura original desta Sprint — mantida reservada para consistência estrutural, sem conteúdo forçado nesta versão.

Psiquiatria clínica contemporânea, em relação de fronteira e distinção explícita com a psicanálise — relevante sobretudo para reafirmar, com fundamentação própria, os limites já registrados em [Documento-Mestre.md §5](../../Documento-Mestre.md#5-princípios-éticos) (não substituição do profissional).
