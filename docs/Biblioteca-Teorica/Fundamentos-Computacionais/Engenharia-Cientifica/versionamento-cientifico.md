# Versionamento Científico

## Metadados

- **Categoria**: Engenharia Científica
- **Tópico**: Versionamento Científico (Scientific Versioning)
- **Definição**: Prática de registrar, de forma datada, identificável e imutável, o estado de um corpo de conhecimento científico em pontos específicos no tempo, permitindo distinguir o que era válido em cada versão e auditar mudanças entre versões.
- **Área científica de origem**: Engenharia de Software aplicada à Ciência Aberta / Gestão de Dados Científicos.
- **Referências principais**: Wilkinson, M. D. et al. (2016). "The FAIR Guiding Principles for Scientific Data Management and Stewardship". *Scientific Data*, 3, 160018. DOI: 10.1038/sdata.2016.18; Ram, K. (2013). "Git Can Facilitate Greater Reproducibility and Increased Transparency in Science". *Source Code for Biology and Medicine*, 8, 7. DOI: 10.1186/1751-0473-8-7.
- **Tópicos relacionados**: [Reprodutibilidade](reprodutibilidade.md); [Auditoria Científica](auditoria-cientifica.md)
- **Status**: Catalogado
- **Observações**: Já praticado desde a Sprint 30, que certificou a Base Científica como versão 1.0, com critério explícito e documentado para abertura futura de uma v2.0 ([Base-Cientifica-v1.0.md, "Condições para abertura da Base Científica v2.0"](../../../Base-Cientifica-v1.0.md#condições-para-abertura-da-base-científica-v20)).

## Aplicação no PsycheAI

Fundamenta cientificamente o versionamento da Base Científica (v1.0, congelada desde a Sprint 30) e o versionamento por commit Git de cada documento — toda alteração de princípio permanente exige processo formal registrado, nunca uma edição silenciosa.

## Componentes da Plataforma relacionados

Nenhum implementado nesta versão além do próprio controle de versão Git do repositório — sem ferramenta de versionamento científico dedicada.

## Relação com a Base Científica

Versionamento científico é o mecanismo que permite à Base Científica evoluir (Fase 1 → Fase 2, v1.0 → futura v2.0) sem perder rastreabilidade histórica de o que mudou, quando e por quê.
