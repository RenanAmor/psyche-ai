# Representação Vetorial

## Metadados

- **Categoria**: Processamento Computacional da Linguagem
- **Tópico**: Representação Vetorial (Vector Space Model)
- **Definição**: Princípio geral, anterior aos embeddings neurais modernos, de representar unidades de informação (documentos, termos, consultas) como vetores em um espaço matemático, permitindo operações de similaridade e distância como proxy computacional de similaridade semântica.
- **Área científica de origem**: Ciência da Computação / Álgebra Linear aplicada.
- **Referências principais**: Salton, G.; Wong, A.; Yang, C. S. (1975). "A Vector Space Model for Automatic Indexing". *Communications of the ACM*, 18(11), 613–620. DOI: 10.1145/361219.361220.
- **Tópicos relacionados**: [Embeddings](embeddings.md); [Recuperação de Informação](recuperacao-de-informacao.md)
- **Status**: Catalogado
- **Observações**: Modelo original de Salton (1975) usava vetores esparsos (TF-IDF); os embeddings neurais modernos ([embeddings.md](embeddings.md)) são a evolução densa/aprendida do mesmo princípio.
