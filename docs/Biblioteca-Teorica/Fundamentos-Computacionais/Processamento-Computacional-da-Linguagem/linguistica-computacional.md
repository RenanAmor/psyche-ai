# Linguística Computacional

## Metadados

- **Categoria**: Processamento Computacional da Linguagem
- **Tópico**: Linguística Computacional (Computational Linguistics)
- **Definição**: Disciplina que estuda a linguagem humana a partir de uma perspectiva computacional, desenvolvendo formalismos (gramáticas formais, modelos estatísticos) que descrevem estrutura linguística de forma tratável por algoritmos — fundamento teórico do NLP.
- **Área científica de origem**: Linguística / Ciência da Computação.
- **Referências principais**: Chomsky, N. (1957). *Syntactic Structures*. Mouton. ISBN 978-3-11-017279-9; Jurafsky, D.; Martin, J. H. (2023). *Speech and Language Processing* (3rd ed. draft). Pearson/online.
- **Tópicos relacionados**: [Processamento de Linguagem Natural](processamento-de-linguagem-natural.md); [Tokenização](tokenizacao.md)
- **Status**: Catalogado
- **Observações**: Não confundir com [../../Linguistica/README.md](../../Linguistica/README.md), pasta reservada da Biblioteca Teórica para a Semiótica (Saussure, Jakobson, Benveniste) como ciência auxiliar da psicanálise — disciplinas distintas que compartilham o objeto "linguagem", mas com métodos e propósitos diferentes.

## Aplicação no PsycheAI

Fornece o arcabouço teórico (segmentação, estrutura sintática, ambiguidade lexical) que orienta como o texto do discurso registrado é dividido e normalizado antes de qualquer classificação — base teórica indireta, sem componente próprio dedicado na plataforma.

## Relação com a Base Científica

A Linguística Computacional fornece o vocabulário formal para descrever a estrutura do dado textual extraído; a Fundamentação Psicanalítica decide separadamente o que, nessa estrutura, tem relevância clínica — as duas operam em camadas distintas, sem sobreposição de método.

## Relação com os Motores
