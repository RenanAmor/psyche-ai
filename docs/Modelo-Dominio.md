# Modelo de Domínio — PsycheAI

> Versão 1.0

O domínio do PsycheAI é a observação longitudinal do discurso humano.

O sistema não interpreta.

O sistema não diagnostica.

O sistema organiza o discurso para tornar recorrências observáveis ao longo do tempo.

---

# Objetos Fundamentais

## Discurso

Representa todo conteúdo produzido pelo sujeito.

É a unidade fundamental do sistema.

---

## Sessão

Agrupa discursos produzidos em um mesmo contexto temporal.

---

## Memória Longitudinal

Representa o histórico completo das sessões de um sujeito.

É responsável pela continuidade do discurso ao longo do tempo.

---

## Evento Discursivo

Representa uma ocorrência registrada durante o discurso.

Todo discurso é composto por eventos discursivos.

---

## Recorrência

Representa um evento discursivo que reaparece ao longo da memória longitudinal.

A recorrência não possui interpretação clínica.

Representa apenas um fato observável.

---

## Observação

Representa o registro produzido pelo sistema a partir das recorrências identificadas.

Observações são descritivas.

Nunca interpretativas.

---

# Relações

```text
Sessão
   │
   ├── Discurso
   │        │
   │        └── Evento Discursivo
   │
   ▼
Memória Longitudinal
   │
   ▼
Recorrências
   │
   ▼
Observações
```

---

# Princípios

- O discurso é o centro do domínio.
- Toda informação é preservada.
- O sistema registra eventos.
- O sistema identifica recorrências.
- O sistema produz observações.
- O sistema nunca interpreta.
- O analista permanece responsável pela interpretação.
