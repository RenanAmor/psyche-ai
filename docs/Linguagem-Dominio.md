# Linguagem do Domínio — PsycheAI

> Versão 1.0

Este documento define o vocabulário oficial do PsycheAI.

Toda implementação deverá utilizar exclusivamente estes termos.

---

# Discurso

Conteúdo produzido pelo sujeito.

---

# Sessão

Conjunto de discursos produzidos em um mesmo contexto temporal.

---

# Evento Discursivo

Unidade registrada durante o discurso.

---

# Memória Longitudinal

Histórico completo das sessões.

---

# Recorrência

Evento discursivo que reaparece ao longo da memória longitudinal.

---

# Observação

Registro produzido pelo sistema a partir das recorrências identificadas.

---

# Analista

Profissional responsável pela interpretação clínica.

O analista não é substituído pelo sistema.

---

# Sujeito

Pessoa cujo discurso é observado.

---

# Princípios

- Um termo possui apenas um significado.
- Não existem sinônimos no domínio.
- O código deve utilizar esta mesma linguagem.
- Toda documentação futura deverá utilizar estes termos.
