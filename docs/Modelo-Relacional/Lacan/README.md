# Modelo Relacional — Lacan

> Síntese das relações científicas entre os onze conceitos lacanianos canônicos ([Ontologia-Lacan.md §3](../../Ontologia-Lacan.md#3-conceitos-fundamentais)). Cada relação individual, com fundamentação bibliográfica completa, está documentada em [../Conceitos/](../Conceitos/). Este documento agrupa e organiza essas relações por agrupamento conceitual, não substitui os documentos individuais.

## Os onze conceitos

Significante; Cadeia significante; Metáfora; Metonímia; Registro Simbólico; Registro Imaginário; Registro Real; Outro; Objeto a; Falta; Desejo (formulação lacaniana).

## Os três agrupamentos ([Ontologia-Lacan.md §4](../../Ontologia-Lacan.md#4-relações-conceituais))

| Agrupamento | Conceitos | Lógica interna |
|---|---|---|
| Estrutura da linguagem | [Significante](../Conceitos/significante.md), [Cadeia significante](../Conceitos/cadeia-significante.md), [Metáfora](../Conceitos/metafora.md), [Metonímia](../Conceitos/metonimia.md) | Como o material discursivo se organiza e produz efeitos de sentido, por substituição ou deslizamento |
| Registros (RSI) | [Registro Simbólico](../Conceitos/registro-simbolico.md), [Registro Imaginário](../Conceitos/registro-imaginario.md), [Registro Real](../Conceitos/registro-real.md) | Quadro topológico dentro do qual toda a experiência se situa; o sistema só acessa o Simbólico |
| Sujeito e falta | [Outro](../Conceitos/outro.md), [Falta](../Conceitos/falta.md), [Objeto a](../Conceitos/objeto-a.md), [Desejo lacaniano](../Conceitos/desejo-lacaniano.md) | Lógica pela qual o sujeito se constitui como incompleto na relação com a linguagem e com o Outro |

## Encadeamento entre agrupamentos

Conforme [Ontologia-Lacan.md §4](../../Ontologia-Lacan.md#4-relações-conceituais): a cadeia significante opera no registro Simbólico, por metáfora e metonímia; ao representar o sujeito, todo significante deixa um resto — a falta — cujo correlato objetal é o objeto a; é dessa falta, articulada ao Outro, que o desejo se sustenta, sempre deslizando metonimicamente, sem se fixar.

```
Significante ←→ Cadeia significante
                   │ (opera no registro)
                   ▼
     Registro Simbólico ←→ Registro Imaginário
                   │              (Registro Real escapa a ambos)
                   │ (movimentada por)
                   ▼
          Metáfora ←→ Metonímia
                   │ (deixa resto: Falta)
                   ▼
     Outro ──→ Falta ←→ Objeto a ──→ Desejo lacaniano
       ↑_________________________________|
              (desejo do desejo do Outro)
```

## Auditoria contra o código real (observabilidade)

Reaproveita a auditoria já feita em [Modelo-Observacional/README.md](../../Modelo-Observacional/README.md):

- **[Metonímia](../Conceitos/metonimia.md)**: único rótulo lacaniano efetivamente produzido, por reclassificação de Repetição (nunca observa por conta própria).
- **[Metáfora](../Conceitos/metafora.md)**: mapeada na tabela de reclassificação do Lacan Engine, nunca efetivamente disparada.
- **[Significante](../Conceitos/significante.md), [Cadeia significante](../Conceitos/cadeia-significante.md), [Registro Simbólico](../Conceitos/registro-simbolico.md), [Registro Imaginário](../Conceitos/registro-imaginario.md), [Registro Real](../Conceitos/registro-real.md), [Outro](../Conceitos/outro.md), [Falta](../Conceitos/falta.md), [Objeto a](../Conceitos/objeto-a.md), [Desejo lacaniano](../Conceitos/desejo-lacaniano.md)**: nenhuma representação computacional definida — nove conceitos sem qualquer observação, por definição teórica, na maioria dos casos ([Registro Real](../Conceitos/registro-real.md), [Objeto a](../Conceitos/objeto-a.md), [Significante](../Conceitos/significante.md), [Desejo lacaniano](../Conceitos/desejo-lacaniano.md) são limites absolutos e permanentes).
