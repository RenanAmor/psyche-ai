# Matrizes — Modelo Relacional

> Seis matrizes que consolidam, sob diferentes eixos, as relações já documentadas conceito a conceito em [../Conceitos/](../Conceitos/). Nenhuma matriz introduz dado novo — cada uma agrega, reorganiza e torna consultável o que já está fundamentado nos 21 documentos individuais, na Biblioteca Teórica e no Modelo Observacional.

| Matriz | Eixos | Fonte primária |
|---|---|---|
| [Conceito-x-Conceito.md](Conceito-x-Conceito.md) | Conceito × Conceito | Seções "Relações Científicas" dos 21 documentos de [../Conceitos/](../Conceitos/) |
| [Motor-x-Conceito.md](Motor-x-Conceito.md) | Motor × Conceito | Seções "Motores envolvidos" dos 21 documentos; auditoria de [Modelo-Observacional/README.md](../../Modelo-Observacional/README.md) |
| [Conceito-x-Obra.md](Conceito-x-Obra.md) | Conceito × Obra | Campo "Obras relacionadas" de [Biblioteca-Teorica/Conceitos/](../../Biblioteca-Teorica/Conceitos/) |
| [Conceito-x-Autor.md](Conceito-x-Autor.md) | Conceito × Autor | Campo "Autores relacionados" de [Biblioteca-Teorica/Conceitos/](../../Biblioteca-Teorica/Conceitos/) |
| [Conceito-x-Evidencia.md](Conceito-x-Evidencia.md) | Conceito × Evidência | Campo "Evidências produzidas" de [Modelo-Observacional/Conceitos/](../../Modelo-Observacional/Conceitos/) |
| [Conceito-x-Observabilidade.md](Conceito-x-Observabilidade.md) | Conceito × Observabilidade | As cinco perguntas Sim/Não de [Modelo-Observacional/Conceitos/](../../Modelo-Observacional/Conceitos/) |

## Por que seis matrizes, e não uma só

Cada matriz responde a uma pergunta distinta que nenhuma das outras responde sozinha: quais conceitos se relacionam entre si (Conceito×Conceito); quais componentes do sistema já implementam ou poderiam implementar cada conceito (Motor×Conceito); de onde vem a fundamentação bibliográfica de cada conceito (Conceito×Obra, Conceito×Autor); e o que, hoje, o sistema efetivamente observa e produz para cada um (Conceito×Evidência, Conceito×Observabilidade). Juntas, as seis matrizes permitem auditar qualquer afirmação relacional feita em [../Conceitos/](../Conceitos/) sob múltiplos eixos independentes, sem duplicar a fundamentação em cada uma.
