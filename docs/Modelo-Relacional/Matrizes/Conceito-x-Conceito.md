# Matriz Conceito × Conceito

> Relações científicas entre os 21 conceitos canônicos, consolidadas a partir dos 21 documentos de [../Conceitos/](../Conceitos/). Dada a esparsidade da matriz de adjacência 21×21 (a maioria dos 420 pares possíveis não tem relação fundamentada na literatura catalogada), esta matriz é apresentada como **lista de arestas** — representação equivalente e mais legível que a grade completa, sem omitir nenhuma célula não vazia. `↔` indica relação bidirecional (ver seção "Relações bidirecionais" do conceito); `→` indica relação direcional (antecedente → consequente).

## Como ler esta matriz

Cada linha equivale a uma célula não vazia da matriz de adjacência 21×21 (conceito-linha × conceito-coluna). Fundamentação bibliográfica completa de cada aresta (obra, autor, capítulo) está na seção "Fundamentação" do documento de Modelo Relacional do conceito de origem, em [../Conceitos/](../Conceitos/). Nenhuma aresta foi adicionada sem essa fundamentação prévia — ver [../README.md, "Critério de relacionamento"](../README.md#critério-de-relacionamento).
