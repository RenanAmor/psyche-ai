## Limites da observação

O sistema **não pode afirmar**:
- significado;
- intenção;
- desejo;
- significante;
- diagnóstico;
- hipótese clínica.

Os Nós Borromeanos (RSI) não têm, nesta versão, base ontológica ou estrutural definida ([Roadmap.md "Sprints futuras"](../../Roadmap.md)).
