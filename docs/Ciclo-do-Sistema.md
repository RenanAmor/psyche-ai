# Ciclo do Sistema — PsycheAI

> Versão 1.0

Este documento descreve o ciclo operacional do PsycheAI desde a entrada de um discurso até a produção de observações.

---

# Visão Geral

O sistema executa sempre o mesmo ciclo.

```text
Entrada
    │
    ▼
Registro do Discurso
    │
    ▼
Organização da Sessão
    │
    ▼
Atualização da Memória Longitudinal
    │
    ▼
Identificação de Recorrências
    │
    ▼
Produção de Observações
    │
    ▼
Persistência
```

---

# Etapa 1 — Registro do Discurso

O sistema recebe o discurso exatamente como foi produzido pelo sujeito.

Nenhuma alteração é realizada.

---

# Etapa 2 — Organização da Sessão

O discurso é associado à sessão correspondente.

A sessão representa o contexto temporal do registro.

---

# Etapa 3 — Atualização da Memória Longitudinal

A sessão é incorporada ao histórico completo do sujeito.

A ordem cronológica é preservada.

---

# Etapa 4 — Identificação de Recorrências

A memória longitudinal é analisada para localizar eventos discursivos que reaparecem.

Nenhum significado é atribuído.

---

# Etapa 5 — Produção de Observações

O sistema registra as recorrências encontradas.

As observações descrevem apenas fatos observáveis.

---

# Etapa 6 — Persistência

Todas as informações produzidas durante o ciclo são armazenadas.

O histórico permanece íntegro.

---

# Princípios

- O ciclo sempre ocorre nesta ordem.
- Nenhuma etapa pode ser ignorada.
- Nenhuma etapa realiza interpretação clínica.
- O ciclo produz observações, nunca diagnósticos.
